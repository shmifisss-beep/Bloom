# KuroCraft — Telegram-бот управления меню

Этот проект даёт вам Telegram-бота, через который можно менять цены, добавлять и
удалять блюда. Изменения сразу доступны сайту через небольшой API — сайт
подтягивает актуальное меню при каждой загрузке.

Всё работает в одном процессе: и API, и бот запускаются одной командой.

---

## 1. Создать бота через @BotFather

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`, следуйте подсказкам (укажите имя и username бота).
3. BotFather пришлёт **токен** вида `123456789:AAExample...` — сохраните его.

## 2. Узнать свой Chat ID

1. Отправьте вашему новому боту `/start` (пока ничего не заработает — это нормально).
2. Пока бот не задеплоен, он не ответит. Задеплойте его (шаг 3), затем напишите `/start` —
   если ваш ID ещё не в списке администраторов, бот покажет вам ваш **Chat ID** в ответном сообщении.
3. Скопируйте этот ID.

## 3. Деплой (рекомендация: Railway.app)

Бот должен работать **24/7**, иначе не будет отвечать. Проще всего — Railway
(бесплатного пробного баланса хватает надолго для такого лёгкого бота).

### Вариант А — через Railway (проще всего)

1. Зайдите на [railway.app](https://railway.app), зарегистрируйтесь (можно через GitHub).
2. Создайте новый проект → **Deploy from GitHub repo** (сначала загрузите эту папку
   к себе на GitHub — можно через веб-интерфейс GitHub, создав новый репозиторий
   и перетащив файлы) **или** используйте `railway up` через Railway CLI прямо из этой папки:
   ```bash
   npm i -g @railway/cli
   railway login
   railway init
   railway up
   ```
3. В настройках проекта на Railway откройте вкладку **Variables** и добавьте:
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_CHAT_IDS` — ваш Chat ID (можно временно оставить пустым, узнать ID из логов после первого /start, затем вписать и передеплоить)
4. Railway автоматически даст вам публичный URL вида `https://your-app.up.railway.app`
   — он понадобится для сайта (шаг 5). Откройте вкладку **Settings → Networking → Generate Domain**, если URL не создался автоматически.

### Вариант Б — свой VPS

```bash
git clone <ваш-репозиторий>
cd kurocraft-bot
npm install
cp .env.example .env
# впишите BOT_TOKEN и ADMIN_CHAT_IDS в .env
npm start
```
Чтобы процесс не останавливался при закрытии терминала, используйте `pm2`:
```bash
npm i -g pm2
pm2 start server.js --name kurocraft-bot
pm2 save
```

## 4. Проверка

Напишите боту `/start`. Если ваш Chat ID уже в `ADMIN_CHAT_IDS` — увидите меню
администратора. Команды:

- `/menu` — посмотреть и отредактировать меню (по категориям)
- `/qoshish` — добавить новое блюдо (бот задаст вопросы по шагам)
- `/bekor` — отменить текущее действие

В карточке блюда доступны кнопки:
- **✏️ Изменить цену** — бот попросит прислать новую цену числом
- **⭐/☆ Добавить/убрать из "Избранного"** — показывается ли блюдо в топ-подборке на сайте
- **🗑 Удалить**

## 5. Подключить сайт к живому меню

После деплоя у вас есть публичный URL (например `https://your-app.up.railway.app`).
API меню доступен по адресу:

```
https://your-app.up.railway.app/api/menu
```

Откройте файл `src/config.js` в проекте сайта и впишите туда этот адрес:

```js
export const API_BASE_URL = 'https://your-app.up.railway.app';
```

Пересоберите и передеплойте сайт — теперь он будет подтягивать актуальные
цены и позиции меню с сервера при каждой загрузке страницы. Если сервер
временно недоступен, сайт автоматически покажет резервную копию меню,
встроенную в сборку, — так что сайт никогда не сломается из-за бота.

## Структура проекта

```
kurocraft-bot/
├── server.js       — Express API + Telegram-бот (один процесс)
├── db.js           — чтение/запись data/menu.json
├── data/menu.json  — сама база данных меню (простой JSON-файл)
├── .env.example    — пример переменных окружения
└── package.json
```

## Важно про хранение данных

Меню хранится в обычном JSON-файле `data/menu.json`. Это просто и не требует
базы данных, но у большинства облачных хостингов (включая бесплатный тир
Railway при пересборке) файловая система **не гарантированно постоянна между
деплоями**. Если будете часто передеплоивать бота — рекомендую позже
перенести хранение в настоящую БД (например, Railway сам предлагает бесплатный
PostgreSQL/SQLite volume в один клик). Для начала и тестирования — текущего
решения более чем достаточно.
